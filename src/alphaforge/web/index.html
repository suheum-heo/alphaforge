04 / BUILT TO BE AUDITED

The boundaries matter.

01

Information available then

Features use closed hourly candles only. Missing hours invalidate affected samples. Train-only scaling and contiguous asset sequences prevent hidden shortcuts.

02

Time stays in order

Chronological splits purge labels that cross a boundary. Validation makes the choices; held-out observations measure what happened afterward.

03

Costs remain visible

Delayed execution, fees, slippage, position changes, and terminal liquidation are included. No leverage, shorts, or actual exchange orders.
