# Frozen hourly inference models

These BTC/ETH Transformer bundles come from the extended study's validation-selected
family. They are published for reproducible hourly inference, not as a profitable
trading strategy. Model fitting ends in December 2025; validation ends in June 2026.
The scheduler never retrains these models. Promotion requires a new versioned registry.

`registry.json` verifies each metadata file; metadata verifies its tensor checkpoint.
No raw candles, personal data, exchange credentials, or pickled estimators are included.
